# 售前代码边界与迁移兼容

[文档导航](../README.md) · [当前实现](current-system.md)

项目源自学院答疑 Agent，当前目标是帮助官网游客找到合适课程、前往官网付款，并将无法解决的问题交给相应课程售前。课程内容与联系方式必须来自可信资料和配置。

## 保留的能力

- 课程选课引导、官网课程查询、付款页面引导、课程售前映射与转人工。
- 课程正文上传、解析、切片、向量和词法检索、重排、来源引用及无依据拒答。
- 游客访问、内部管理员登录、课程资料与售前映射维护。
- 同步与流式问答、内部账号会话与上下文、会话过期清理。
- 健康检查、运行指标、限流与生产配置校验。

保留会话上下文是为支持咨询追问，不是学院薄弱点分析；目前游客仍为单轮。付款能力是引导用户进入官网课程页，尚不承担订单创建、收款或支付结果核验。

## 已移除的能力

- 学员薄弱点总结、进阶资料推荐、学习路径网页搜索及其长任务执行器。
- 代码 ZIP 入库、代码解包、代码语言元数据与学员代码存储入口。
- 截图识别、OCR、视觉模型调用和截图问答分支。
- 学员通用编程答疑、无知识库依据时的模型兜底和网页搜索工具。
- 跨会话长期记忆、MCP 工具适配、学院岗位规则、学习陪伴和技能加载。
- 学院演示账号与内部主题种子、学院角色空间推导，以及旧 FDE 批量搬运脚本。

对应路由、服务、配置、响应模型、指标与不用的数据模型一并删除。历史 HTML 规划材料保留作背景，不代表当前代码中存在这些模块。

## 已有数据库与接口兼容

重启服务时，种子流程会将原 `p0_admin` 的 `teaching` 角色幂等迁移为 `admin`，保留密码和已有课程成员关系。不会批量提升其他教学账号；其他维护账号需要明确配置 `admin` 角色。课程访问只读取课程空间的成员关系，旧学员和公司空间成员不会扩大检索范围。

旧数据库中的历史任务、记忆等表及多余列不会自动删除，也不执行破坏性数据库迁移。新代码不再映射任务和长期记忆表。`users.is_teaching` 仅保留默认写入以兼容旧库的非空列，不参与授权、不对外返回；其他可空历史列可以留在旧库中。

登录响应已去掉 `is_teaching`、`advisor_id`、`position_key`，使用 `role` 与 `can_manage_documents` 表达管理员权限；问答响应已去掉截图提取字段，运行指标已去掉截图和学员通用答疑计数。当前演示页不依赖这些字段，外部旧客户端如有使用需同步调整。

```powershell
python -m pytest tests
python scripts/smoke_kernel.py

```

回归覆盖选课、付款引导、转人工、同步与流式知识库问答、无依据不调用模型、会话保存和失败回滚、旧管理员迁移、课程空间隔离及上传限制。真实课程资料和实际支付体验仍按 L0 运营流程验收。
