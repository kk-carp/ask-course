## 服务结构

[服务入口](../../backend/main.py)挂载健康检查、指标、认证、文档、问答、匿名问诊、会话和售前映射路由，启动时初始化数据库与向量模型。内部演示页面与官网嵌入脚本由 [spa.py](../../backend/spa.py) 托管。

[ask.py](../../backend/routes/ask.py) 接收请求，[ask_orchestrator.py](../../backend/services/ask_orchestrator.py) 统一编排访客上下文与回答。[intent_router.py](../../backend/services/intent_router.py) 优先处理讲价退款发票、找顾问、付款和明确的选课请求。访客说出具体方向时先展示相关课程；只在方向不明或无法命中时追问目标。已推荐课程的基础、硬件和时间可继续补充，但不阻塞首次展示。其他课程内容问题先用官网文字快照回答公开事实，再由 [qa_service.py](../../backend/services/qa_service.py) 检索知识库。`/consultations` 保留结构化接口，官网组件使用统一的 `/ask` 多轮对话。

游客仅访问服务端限定的课程空间。自由问答与选课问诊共用匿名访客状态：最近三轮问答在服务端保留 24 小时，用于本地追问检索；短回答按上一轮问题解释，已确认的选课字段无需重复回答。历史原文不会作为对话消息发送给回答模型，回答仍只依据本轮检索片段。会话通过签名的访客 Cookie 隔离。知识库正文需要上传文本或可解析文档；官网列表和详情接口不代替正文入库，图片正文仍需先文本化。

[question_decomposition.py](../../backend/services/question_decomposition.py) 拆分带问号、逗号或常见连接词的明确并列问题，自我介绍与选课画像陈述保持完整。每个问题复用单问题编排，合并答案、依据、课程卡片与顾问入口；游客整条咨询保存为一轮。多问题的 `/ask` 和 `/ask/stream` 均返回 `intent=multi_question`，`hit=true` 仅表示至少一项有依据，不能当作所有问题已解决。某一项上游服务暂不可用时保留其他答案，全部查询不可用则返回服务错误。价格与观看期限当前仍走知识库，并未接入官网实时价格和有效期字段。

## 转人工行为

内容回答命中时直接返回。未命中但已找到相关课程候选时先引导选课；其他未命中情况尝试解析联系人。明确找顾问、讲价、退款和发票等意图直接进入人工承接流程。

[handoff_service.py](../../backend/services/handoff_service.py) 按以下顺序寻找有效出口：

1. 数字课程 ID 对应的官网详情售前码。
2. 本地 `topic_owners` 的课程 ID 精确映射。
3. 问题文本中的课程关键词映射。
4. `HANDOFF_FALLBACK_CONTACT` 配置的兜底联系人。

无有效出口、关闭转人工或解析异常时可能返回 `configured=false`。`hit=false` 不一定意味着已经成功转人工，调用方还需检查 `owner` 和 `related_courses`；系统故障也不能视为普通知识未命中。

## 配置与上线前提

配置入口为 [.env.example](../../.env.example)，完整定义和环境校验见 [config.py](../../backend/config.py)。`APP_ENV=prod` 拒绝默认密钥与默认演示密码，要求严格课程内容校验、启用人工承接并配置有效格式的真实兜底链接。格式校验不能证明联系人实际可访问，仍需运营核验。

课程正文、在售目录、负责人和真实售前映射按 [L0 手册](../operations/L0_OPERATIONS.md)准备。[官网试运行准出](../operations/PILOT_LAUNCH.md)另外要求课程审核清单、购买页和二维码核验。启动不再插入占位售前映射，并清理旧占位行。

## 已知限制与后续规划

- 已提供方向优先的推荐和保守的自然语言画像提取；宽泛目标仍需追问具体方向。42、43、99 可展示官网相关课程，只有运营完整审核后才会按个人适配条件筛选并开放购买入口。真实课程资料和人工验收尚未完成。
- 已提供同源嵌入脚本，官网团队仍需配置反向代理、页面嵌入、发布与回滚。
- 学院薄弱点总结、进阶资料、代码入库、OCR、长期记忆及 MCP 已从代码中移除，详见[售前代码边界](presales-scope.md)。
- 限流及原问答计数仍是进程内状态，多副本部署需要共享限流；新增漏斗事件持久化在数据库。
- 内容安全审核尚未接入；真实课程资料和人工承接是否齐全需按 L0 门禁确认。
