# 售前助手产品需求与规则

[文档导航](../README.md) · [当前实现](../architecture/current-system.md) · [改进计划](../development/roadmap.md)

更新：2026-10-09。本文合并早期需求分析、PRD 和问诊规则中仍有效的约定，说明目标和业务边界；是否已经实现，以当前实现为准。旧稿中的临时权重、固定问诊轮次、行业转化率和未经确认的接口假设不作为验收依据。

## 目标与范围

帮助访客了解课程、选择适合的学习路径，并进入官网购买页或联系对应课程顾问。核心用户为高校学生；教师、企业采购和需要个性化方案的咨询转人工。内部售前可使用资料与问答工具，内部管理员负责内容和联系人维护。

保留已确认目标：42、43、99 三门课首发；对接官网普通登录账号，不新建会员等级；登录后关联当前游客咨询、跨设备读取本人历史。当前官网暂时无法修改且没有加载助手脚本，因此真实客户接入暂缓，独立游客页面仅用于分阶段验证，不代替完整首发验收。

月底目标为内部候选版与证据包，公开发布服从准出结果，不以日期强制上线。未通过课程审核、身份联调或运维签收时，相应能力保持关闭。

本期不执行支付、订单创建、退款、优惠券发放，不查询个人已购课程、学习进度或权益；不提供包就业、项目完成或证书效力保证。运行时 OCR、跨品牌推荐、长期学习记忆和通用工作流编辑器不在当前范围。

## 主要流程

- 目标尚不明确：先确认学习方向；方向明确后先展示相关课程，再按需补基础、硬件、每周时间和期限，跳过已知信息。不要求每个用户完成固定轮数问诊。
- 用户直接询问课程事实：优先回答有依据的项目，不以收集画像阻塞回答。未知或冲突项明确提示需要确认。
- 用户已经选定课程：走短路径，给出经资格校验的详情或购买入口；不强制重新问诊。
- 用户主动找人、议价、退款、发票或提出需要人工确认的承诺：提供有效顾问入口。公开标价和可核实公开优惠可以查询，不与议价混为一谈。
- 没有可靠资料：拒绝猜测；有方向相关候选时可继续引导选课，否则尝试人工出口。未配置有效联系人时如实告知。
- 多个明确并列问题：按原顺序逐项展示，单项失败不覆盖其他已有依据的回答；严重错误不能被“部分命中”掩盖。

## 推荐与事实规则

画像包括方向、学习目标、基础、设备、时间及明确提及的专业、预算和证书诉求。未知字段保持未知，不能当作不满足条件，也不能补造。

`recommendable` 只表示可以展示方向相关课名和简介；`approved` 且完整门禁通过后才可作个体适配推荐及购买引导。基础、硬件和最低投入等硬条件不满足时不得通过兜底重新推荐。

推荐理由必须落到真实课程字段或已核实资料，说明适用条件和待确认项。排序服务不能改变课程资格；不承诺采用旧稿中的固定百分比权重。推荐权重本身不新增销售评审流程，事实与课程销售资格仍须审核。

价格、公开优惠、在售状态和购买地址以指定官网业务数据为准；过期缓存不能在上游失败时继续作为当前价格。观看期限、目录、证书与授课安排必须有可追溯依据，冲突不得由模型自行裁决。购买时再次检查资格，历史课程卡片不能证明当前售价和可购买状态。

最低课程正文包括适用人群、课程目录、学习安排、结业证书；原始图片需在入库前文本化并由运营核对。不得用售前问答泄漏付费课程视频、逐字稿或绕过付费的信息。

## 身份、历史与交互

官网游客与客户、内部管理员分开授权。游客历史默认 24 小时，客户默认 90 天，读取、改名和关联不延期。仅关联当前选中、有效且未删除的游客咨询，关联后原游客失去访问权，不自动合并其他游客记录。

登录、退出、切号应清空旧视图、草稿和在途请求，再加载新主体历史；这项目标依赖真实官网凭据和事件，目前尚未接通。详细规则见[客户身份与历史归属](../integration/官网客户身份与历史归属.md)。

官网目标入口为全站加载一次的咨询组件，桌面右侧面板、移动端全屏，样式及弹层通过 Shadow DOM 隔离。历史支持主题短句、搜索、重命名和删除；回答来源默认折叠。内部管理入口独立，不嵌入官网。

当前独立 `/consult` 页面不连接官网账号，官网退出或切号不会清除其游客记录。它是已有游客能力的独立入口，不是新增身份体系。内部预览使用内存历史，不能代替真实站点门禁验收。

## 人工承接与后续需求

联系入口优先使用对应课程官网售前码，其次课程 ID 映射、关键词映射和真实备用出口；不能因显示二维码就统计为人工已接单。需核实售前码和售后班主任码的用途，避免弹错联系人。

保留早期已确认的协作原则：助手承担初筛并辅助售前，业绩归属参考最近一次人工接触的售前。但有效时间窗、跨渠道口径、纯自然流量归属及核算依据仍待业务确认，当前不自动分配业绩。

后续按实际需求单独评估：现有咨询入口归一、详情板块深链、推荐依据留痕、咨询摘要交接、来源归因、内部售前查询、在线坐席状态和回执。企微接口、值守安排及合法资料未明确时，不声称具备自动推送、加好友统计或在线接管。

主动唤起、线索打分、多渠道互通及售后触达不作为当前开发前置条件；不在 K12 场景收集未成年人在线留资。

## 验收依据

人工准确率至少 95%、对话任务完成率至少 90%、严重错误为零；记录样本分母、评阅人、代码/模型/资料版本及失败案例。自动检查通过率不能代替人工准确率。

业务签收见[预发布验收](../operations/ACCEPTANCE.md)，开放门禁见[试运行准出](../operations/PILOT_LAUNCH.md)。原始评测结果、课程资料和敏感信息保留在受控存储，代码和已删除旧稿可通过 Git 历史追溯。
