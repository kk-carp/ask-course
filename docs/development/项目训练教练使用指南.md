# 项目训练教练使用指南

项目训练教练把 [30 天训练计划](初级开发者30天项目训练计划.md) 变成逐步实践：先给任务，让你自己思考、编写或排查，再检查证据和理解程度。训练记录保存在项目中，下次可以从断点继续。

## 开始第一天

在这个项目的聊天中发送：

```text
$project-training-coach 开始 D1，我今天有 60 分钟。
```

第一回合会先让你建立自己的基线，不会直接替你跑完整套检查或一次布置整周任务。按要求操作，把自己的解释、文件路径或命令结果发回来即可。

技能已保存到本机个人技能目录 `C:/Users/Tianshu/.codex/skills/project-training-coach/`。如果当前聊天的技能列表尚未发现它，可以在新聊天中尝试；也可直接发送以下文本，让当前助手读取技能文件：

```text
请读取 C:/Users/Tianshu/.codex/skills/project-training-coach/SKILL.md，按这个技能开始 D1 项目训练。
```

## 常用说法

- 继续上次：`$project-training-coach 继续训练，我今天只有 30 分钟。`
- 卡住求助：`我卡在这里了，先给方向提示，不要给代码。` 再附上你做过的检查。
- 检查作业：`$project-training-coach 检查 D8 作业，文件在……，先评审我的设计。`
- 检查实现：`$project-training-coach 检查我的反馈 API，改动在……，这是测试结果……`
- 调试训练：`$project-training-coach 开始 D16，带我排查超时，一次只让我检查一个位置。`
- 口试：`$project-training-coach 考核我对 ask.py 的理解，一次只问一个问题。`
- 查看进度：`$project-training-coach 查看进度和还没完成的验证。`
- 结束本次：`今天先到这里，记录断点和下次第一步。`
- 周复盘：`$project-training-coach 复盘这周，帮我挑一个最值得补练的点。`

不用每次背完整提示词。明确告诉教练“继续”“给提示”或“检查这个作业”，并提供必要成果即可。

## 怎样算完成

教练分别检查两件事：功能是否得到验证，以及你能否解释自己的实现。测试结果、失败边界、数据变化和你的回答都会作为证据。

- A0：独立完成。
- A1：查文档、得到提示或概念说明后完成。
- A2：用了 AI 生成的实现或完整答案；保留这次成果，再安排一次独立重做。

你可以随时要求“直接帮我实现”。教练会照做，相关练习记为 A2；工作交付与个人掌握分别记录。

说“做完了”会进入验收；跳过的任务、没运行的测试、环境导致无法完成的检查都会保留。天数按实际训练推进，不会过一天就自动解锁下一天。

## 记录在哪里

[训练进度](training/progress.json) 保存当前训练日、待回答问题、完成记录和补练队列。会话记录会在实际训练后创建到 `docs/development/training/sessions/`，目前尚未开始训练。

同一份项目目录中的新聊天可以读取这些记录继续。将技能用于其他项目时，需要那个项目自己的训练计划和进度；不会把两个项目的记录混在一起。复制到其他电脑时，需一并携带个人技能目录和项目训练记录，并核对项目路径。

训练教练本身不会定时提醒你。按需发起一轮训练即可；提醒需求可以另行安排。
