B10 课程接口的数据口径：① price_tiers 中"31–60 人 ¥89"高于"1–30 人 ¥69"，单价随人数上升，是否为预期口径？② price 为数字、original_price 为字符串（"199.00"），类型不一致是否有意？③ student_count 为 0 而 badge 为 hot，报名人数是否未统计或未对外返回？④ 接口返回的 countdown（阈值 30 天、目标时间为空）实际业务规则是什么？ 前两项影响 Agent 的价格话术与推荐排序；第 ④ 项尤其关键——Agent 若引用倒计时营造紧迫感，必须与实际价格逻辑严格一致，不得虚构截止时间，否则构成虚假促销。 确认三项数据口径 + 倒计时实际规则
