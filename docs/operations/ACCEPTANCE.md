# P0 预发布验收

自动案例和原始答案保存在本地，不提交课程资料或结果。运营需审核案例期望值；生成器只建立待审核的回归基线，不表示已经确认全部事实正确。

## 重复执行

1. 用 `scripts/build_pilot_dataset.py` 根据本地 42、43、99 课程资料生成 74 个案例，审核 `data/eval/pilot_gold.jsonl`，补充真实游客说法和事实期望。
2. 启动预发布，执行 `scripts/evaluate_pilot.py --base-url <预发布地址>`。逐案记录问答、流程失败、事实来源课程与顾问是否匹配。报告保存在 `data/eval/pilot-results.json`。
3. 人工阅读报告中的原始答案，核对内容正确性与三连问逐项完整性。自动通过率仅代表程序检查通过率；不能直接当作问答准确率或任务完成率。
4. 执行 `scripts/check_pilot_readiness.py`、本地回归和官网页面验收。缺少课程审核、备用联系人或页面接入时保持关闭。

本地测试覆盖购买地址/在售校验、错误 ID、二维码不可用、模型故障和逐项错误。真实已审核课程的购买验收必须在预发布追加，不能为了测试提前批准课程。

## 人工签收

- [ ] 运营：审核课程来源、价格、学习期限、目录、基础与设备要求、证书和联系人；确认冲突项并登记审核人和日期。
- [ ] 运营：逐案评阅常规问答，准确率至少 95%；对话任务完成率至少 90%；严重事实、错误购买链接、错误顾问为零。
- [ ] 官网：桌面与手机完整咨询，跨页恢复、多轮推荐、三连问、复制摘要、正确二维码及失败备用出口。
- [ ] 官网：真实审核课程购买按钮到达对应官网购买页；需要登录时流程可继续。终点为购买页，不验收支付/对账。
- [ ] 运维：实际模型并发、延迟、故障重试、完整文件恢复和镜像回滚均在预发布签收。
- [ ] 发布负责人：页面白名单和开关核验，先 5%，连续 7 天无严重问题后再 25% 和扩大；严重错误立即关闭入口。
