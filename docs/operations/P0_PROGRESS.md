# P0 实施与验收清单

按 2026-09-30 对话确认的五项 P0 计划实施。每项代码验证后独立提交并推送。

1. 课程事实：统一提供资料与官网价格/公开优惠，冲突和缺项明确回答，来源和更新时间可追溯。
2. 对话理解：一次语义解析、画像修正、候选顺序指代、比较课程、跨页面续聊。
3. 购买与人工交接：决策卡片、受校验购买入口、顾问摘要与备用联系方式。
4. 部署与响应：固定依赖、自动检查、部署/回滚、数据库备份恢复、并发与逐项输出。
5. 真实课程验收：60–100 个案例、可重复评测、故障与购买链路检查、灰度准出。

## 完成记录

- 第 1 项：三门课文字资料已入库，49 个分片；新增统一事实查询，公开优惠与议价分开。官网价格最多缓存一分钟，请求失败不沿用过期价格。42、43、99 的资料来源与更新日期登记在 `data/course_facts.json`。
- 第 2 项：一次语义解析统一问题拆分、画像更新、课程指代；失败沿用规则。候选课程顺序保存在访客会话，支持按序选择、比较和跨页面续聊。签名访客身份和会话有效期继续校验。
- 第 3 项：课程卡片展示推荐依据、基础/设备条件和需确认事项；购买点击再次校验官方地址、报名状态与页面可访问性。交接摘要包含目标、基础、设备、投入、候选和未解决问题，仅展示供访客复制。二维码加载失败提供已配置的备用出口。
- 第 4 项：JSON 和流式问答共用编排，同步处理移入线程池；多问题完成一项即输出一项。提供加载提示与重试、就绪检查、请求耗时日志、固定直接依赖、容器部署和持续检查。生产环境压测与备份恢复/回滚演练仍需在预发布执行。

## 外部验收依赖

- 运营填写真实内容负责人、生效日期和审核人，完成三门课程销售审核。代码或入库操作不代签运营审核。
- 43、99 的观看期限存在“长期有效”和“购买后一年”冲突；42 的电脑配置和 GPU 要求未明确。
- 官网团队确认购买/登录路径、嵌入代理和发布回滚；真实桌面/手机验收与至少 7 天灰度观察。
- 95% 常规问答准确率、90% 对话任务完成率、严重事实/购买链接/顾问错误为零是准出目标，需要实际评测证明。
