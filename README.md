# 天树探界 · 售前 Agent 助手

面向课程咨询的独立服务，提供课程知识库问答、多轮问诊推荐、购买页引导和售前承接。官网嵌入脚本已提供；真实课程审核、官网部署及灰度验收尚未完成，因此默认不向访客展示入口。

## 从这里开始

- [本地启动](docs/getting-started/README.md)：安装依赖、配置数据库、启动服务和内核自检。
- [L0 内部运营](docs/operations/L0_OPERATIONS.md)：准备课程正文与真实售前映射，执行资料门禁和金标评测。
- [官网试运行准出](docs/operations/PILOT_LAUNCH.md)：运营审核清单、嵌入代码、灰度开关、验收与回滚。
- [开发指南](docs/development/README.md)：代码分层、常用检查和维护入口。
- [全部文档](docs/README.md)：产品规划、技术方案、调研、对接清单和模板。

## 当前能力与边界

- 支持游客咨询和内部账号试用，正文问答使用课程知识库；官网客户校验适配器默认关闭，真实官网登录、退出及切号联动尚未接通。
- 同一条消息里的明确并列问题会逐项回答；问号、逗号及常见连接词均可拆分，需顾问确认的部分不会覆盖已知答案。价格和观看期限仍需要可信资料支持。
- 官网标价和公开优惠直接查询官方字段（最多缓存一分钟），个别讲价、退款、发票及找顾问转人工；未通过课程审核的付款请求不会生成购买链接。
- 内容未命中时按上下文展示相关课程或尝试转人工；无有效联系方式时明确返回未配置。
- 官网组件按课程详情页白名单和稳定访客桶灰度；访客说出方向后先展示相关课程，再按需补充基础、硬件和每周时间。只有完整审核的课程才会按个人条件筛选并提供购买入口。
- 游客自由问答与选课问诊共用 24 小时访客状态；官网公开的 26 门课程已列入审核清单，文字快照保存在 `data/official_course_drafts/`。其中 42、43、99 可展示为与目标相关的课程；完成运营审核前不开放购买入口和官网灰度组件。
- 数据边界：`approved` = 可按适配条件推荐并生成购买入口；`recommendable` = 可展示方向相关课名与简介。42、43、99 的常见事实优先读取 `data/course_facts.json` 中提供资料的来源与更新时间，其他正文细节走数据库检索，官网快照仅作缺资料时的补充。资料冲突明确呈现，不推断观看期限。
- 官网详情页注入：`<script defer src="/agent/widget.js" data-course-id="{id}"></script>`（白名单默认 42/43/99，`PILOT_PERCENT` 控制放量；跨页续聊靠访客 cookie）。
- 官网暂时无法改动且尚未加载助手脚本时，可在助手服务的 `/consult` 独立页面验证游客咨询和历史；仍受课程审核与灰度门禁限制，暂不连接官网会员账号。使用范围见[游客接入](docs/integration/游客接入.md)。

实现细节和已知限制见[当前实现](docs/architecture/current-system.md)。规划中的需求与验收目标不等于已上线能力。代码范围和迁移兼容说明见[售前代码边界](docs/architecture/presales-scope.md)。

## 项目布局

- `backend/`：FastAPI 接口、应用服务、领域规则、基础设施及种子数据。
- `frontend/`：Vue 3 + Vite 咨询组件、独立内部管理页面及构建配置。
- `scripts/`、`tests/`：自检、运营工具与自动化测试。
- `docs/`：按用途分类的项目文档。
- `data/`：课程目录与映射样例、评测集和运行时上传内容。

配置从 [.env.example](.env.example) 开始；课程上传内容和运行时文件不作为项目文档维护。
